# Abstract

The paper formalizes the common model-theoretic structure of logical systems so specification and programming methods can be stated independently of a particular logic. It defines institutions and their morphisms, develops presentations, theories, constraints, and theory combination, and shows how several institutions can be used together. Equational and first-order logic provide detailed examples. [PDF pp. 1–2, 37–47; journal pp. 95–96, 131–141]
